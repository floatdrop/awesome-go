# Code of Conduct

Be kind, be constructive, assume good intent. Discuss the code, not the person. Disagreements about whether something belongs on the list are normal; personal attacks, harassment and discrimination of any kind are not and will get you removed from the project.

Report problems to the maintainers by email or by opening an issue. Reports are handled in confidence.

This code of conduct applies to every space of the project: issues, pull requests, discussions and any other channel where the project is represented.
